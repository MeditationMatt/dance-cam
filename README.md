# DanceCam

Record a dance video with your own song as the soundtrack.

**Live:** https://meditationmatt.github.io/dance-cam/

1. Open in Safari (iPhone works)
2. Pick a song file (MP3 / M4A / WAV / AAC) — not Apple Music or Spotify streams
3. Record → Stop → Save

Mic is off by default so only the music is on the soundtrack.

## Mocap Mirror

Webcam full-body 3D motion capture that drives a Mixamo-rigged character and exports BVH / GLB.
